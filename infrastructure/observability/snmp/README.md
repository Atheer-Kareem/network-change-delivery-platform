# SNMP module provenance

`generator.yml` is the reviewed, secret-free source for the narrow
`ncdp_if_mib` module. `snmp-modules.yml` is generated output and must not be
edited manually. Neither file contains an SNMP auth definition.

The reproducibility check uses the official AMD64-only generator under explicit
emulation:

```text
prom/snmp-generator:v0.30.1@sha256:7302a6703ec9eebdc901b7f1f876121ccaea636121fcb86e8211f6becc53fb43
```

It downloads only the required standard MIB inputs from exact Net-SNMP commit
`c4d46f9f7b5b32bf1d6b61d09bdabaae4ff3cd7a` and verifies each file against the
SHA-256 values embedded in the check script before generation. The temporary
directory is removed after the check.

Verify committed output:

```console
uv run --frozen python scripts/observability/check_snmp_generator.py
```

Regenerate after a reviewed source change:

```console
uv run --frozen python scripts/observability/check_snmp_generator.py --write
```

The check fails when regenerated bytes differ from the committed output. The
generated module is also validated against the exact get/walk and device-view
closure in `network_change_delivery.snmp_mib`.

The exact generated file is excluded from `ansible-lint`: upstream generator
output uses emitter formatting that is not accepted by that repository-wide
hand-authored YAML style gate. YAML parsing, byte-for-byte regeneration, and the
OID-closure validator remain mandatory for this generated artifact.

Future runtime integration will load this module alongside a separate private
auth configuration by repeating `--config.file`. The private auth directory will
be mounted read-only; it is not implemented by 11C-1. The reviewed future
runtime image is:

```text
prom/snmp-exporter:v0.30.1@sha256:e5fd5e8b43ace6c088fe9bf0b37b7fff0e04380bee352be7ec41b853a4dd5859
```
